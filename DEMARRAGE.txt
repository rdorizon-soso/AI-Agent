================================================================================

Commande simple :
  python script.py Jean
  → Résultat : Bonjour Jean!

Avec accents :
  python script.py José
  → Résultat : Bonjour José!

Prénom composé :
  python script.py Jean-Pierre
  → Résultat : Bonjour Jean-Pierre!

Afficher l'aide :
  python script.py -h
  ou
  python script.py --help

================================================================================
  EN CAS D'ERREUR
================================================================================

Erreur : "python: command not found"
  → Assurez-vous que Python 3.7+ est installé
  → Utilisez : python3 script.py [prénom]

Erreur : "Erreur : Le prénom ne peut pas être vide"
  → Vous avez fourni un argument vide ou avec seulement des espaces
  → Utilisez : python script.py "votre_prenom"

Erreur : "the following arguments are required: <prénom>"
  → Vous avez oublié de fournir un prénom
  → Utilisez : python script.py Jean
